`grilling` 스킬과 `domain-modeling` 스킬로 세션을 진행한다 — **grill-with-docs 등가**: 인터뷰만 하는 게 아니라 진행 중 해소되는 용어를 vault 용어집에, 되돌리기 어려운 결정을 decisions에 **그 자리에서 기록**한다 (모아서 나중에 쓰지 않는다).

- 도메인 문서 배치(용어집·결정 기록 위치)는 [docs/agents/domain.md](../../../docs/agents/domain.md)를 따른다 — repo 루트 CONTEXT.md를 만들지 않는다
- 완료(프론티어 빔) 후 분기: 단일 세션 규모 → `/ad:implement` / 티켓화 가능 → 같은 창에서 `/ad:ticket` / 다세션·미성숙 계획 → `/ad:plan`(위키 계획 노트) / 결정 자체가 다수 미결인 안개 → `/wayfinder`
