# eng-review 출처 고지

[`/ad:eng-review`](../../.claude/commands/ad/eng-review.md)와 [review-sections.md](./review-sections.md)는 gstack `plan-eng-review` (v1.60.1.0, commit `7c9df1c`, 2026-07-09)의 리뷰 방법을 한국어로 번안·축약한 것이다. gstack 공통 preamble, 텔레메트리, 학습·brain 저장, 리뷰 로그·대시보드, JSONL 산출물, plan mode 게이트, 다른 gstack 스킬 연쇄 호출은 옮기지 않았고 팀 규격(서비스 카탈로그·공통 서비스·단계 분리·vault 기록)을 더했다.
