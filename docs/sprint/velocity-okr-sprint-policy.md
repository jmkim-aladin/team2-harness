# Velocity-OKR 스프린트 운영 정책

> YouTrack KB: DEV2-A-1122 | 상위: DEV2-A-1095 (2026.05)

## 1. 목적

Velocity 기반 수용량 산정을 스프린트 계획의 기준으로 삼고, 그 위에 OKR 달성 판정을 연결한다.

핵심은 아래 측정 체인을 매월 반복 가능하게 만드는 것이다.

```text
Velocity 수용량 산정
→ 계획 이행률 검증
→ OKR 직결 티켓 완료율 확인
→ KR 달성률 판정
→ 다음 달 목표량 및 리소스 배분 조정
```

4월 회고에서 확인한 문제는 OKR 직결 티켓을 수행했더라도 KR 달성률을 판정할 체계가 없으면 분기 목표의 현재 위치를 설명할 수 없다는 점이다. 따라서 계획의 신뢰도를 먼저 확보하고, 그 위에서 OKR 달성도를 판정한다.

## 2. 월간 계획 수립 원칙

### 수용량 산정

산정식·계획 계수·가용률 보정은 [Velocity 가이드 §4](./velocity-guide.md).

### 백로그 설계

- 계획 백로그 총 SP는 산정 수용량을 초과하지 않도록 설계한다.
- OKR 직결 티켓을 먼저 배치하고, 잔여 수용량에 개선·고도화 티켓을 배치한다.
- 등록 Task SP 상한은 3이다. 초과분은 분할 후 포함한다 ([SP 가이드 §4](./story-point-guide.md)).
- 운영 업무와 스프린트 외 Epic 관리 건은 Velocity 해석에서 분리한다.

## 3. 월말 판정 지표

### 계획 이행 신뢰도

| 지표 | 기준 |
|------|------|
| Sprint Completion Rate | 계획 백로그 총 SP 대비 완료 SP 비율. 목표 90% 이상 |
| Velocity 안정성 | 전월 대비 Velocity 편차 ±20% 이내 |

### OKR 달성 판정

| 지표 | 기준 |
|------|------|
| KR 진척률 자기 보고율 | 월말까지 전원 KR별 진척률 코멘트 게시. 목표 100% |
| OKR 직결 완료율 | 당월 완료 가능한 OKR 직결 티켓의 완료 비율 |
| 분기 OKR 중간 점검 | KR별 달성률, 다음 달 잔여 목표량, 달성 가능성 판정 |

## 4. 산출물

매월 스프린트 마감 시 아래 산출물을 남긴다.

- **수용량 기반 백로그 확정 목록:** 직군/담당자별 수용량과 계획 SP
- **OKR 중간 점검 리포트:** KR 진척률 자기 보고, KR별 달성률, 잔여 목표량
- **실행 분석 리포트:** Sprint Completion Rate, Velocity 추이, OKR 직결 스코핑 정확도
