# eli5 — HTML판

`eli5`와 같은 목표·같은 뼈대를 쓰되, 산출물이 **남에게 보낼 파일 한 장**이다. 갈라지는 지점은 셋뿐이다: 그림이 크다, 글이 더 적다, 파일이 남는다.

목표는 `eli5` §목표 그대로다 — 빠르게, 정확하게, 다시 설명할 수 있게. 이 판에서는 **보낸 사람이 옆에 없다**는 조건이 하나 더 붙는다. 받는 사람이 질문할 곳이 없으므로 첫 패널만 보고 요지를 잡고, 마지막 패널까지 보면 자기 팀에 그대로 옮길 수 있어야 한다.

**호출은 명시 호출뿐이다.** `/eli5-html`(Claude) 또는 `$eli5-html`(Codex)로 사람이 부를 때만 수행한다 — 파일을 언제 남길지는 사람이 정한다.

대상 잡기·구체 사례 규칙·사실 확인 규율·오해 짚기·문체는 `eli5` 스킬의 절차 1~5단계와 §문체를 그대로 따른다. 여기에는 산출물 규격만 적는다.

## 산출 위치 — 경로부터 확인받는다

파일을 만들기 전에 **경로 한 줄을 확인받는다.** 사용자가 경로를 지정했으면 그대로 쓴다.

우선순위: 지정 경로 > 대상 저장소에서 이미 gitignore된 디렉토리(`artifacts/`, `tmp/`, `.local/` 순) > `~/Documents/workspace/.eli5/<repo>/`.
`.gitignore`를 고치지 않는다. 파일명은 `YYYY-MM-DD-eli5-<slug>.html`.
vault·KB에 남길 문서라면 여기서 만들지 말고 `$TEAM2_HARNESS_PATH/policies/knowledge-base-policy.md` 결정 트리를 따른다.

## 패널 규격

한 화면 = 한 패널. **6~7개**로 끝낸다.

| # | 패널 | 그림 | 글 |
|---|---|---|---|
| 1 | 한 줄 | 큰 글씨 한 문장 | 결과 문장, 전문용어 0개 (`eli5` §출력 형식 규칙) |
| 2 | 구체 사례 | 장면 SVG (입력값 → 결과) | 2~3줄, 값 포함 |
| 3 | 그림 | 흐름 또는 구성 SVG 1개 | 상자 라벨만 |
| 4 | 왜 이렇게 하나 | 문제 → 해결 화살표 | 3줄 |
| 5 | 이것만 기억 | 번호 원 3개 | 옮겨 말하기 대본 3문장 (`eli5` §출력 형식 5번 규칙) |
| 6 | 헷갈리기 쉬운 것 | ✗ 착각 → ✓ 실제 대비 | 1~2줄 |
| 7 | 아직 확인 못 함 (선택) | 없음 | 불릿 1~3개 |

- **분량은 목표가 정한다.** 단어 수 상한은 두지 않는다 — 빨리·정확히 이해하고 옮기는 데 필요한 글은 남기고, 그 일을 안 하는 글은 뺀다. 글로 길게 설명하게 되는 곳은 그림으로 옮길 수 있는지 먼저 본다
- 1번 패널만 읽고 닫아도 요지가 남아야 한다. 받는 사람 대부분은 첫 화면에서 멈춘다
- 7번 패널은 확인 못 한 사실이 있을 때만 넣는다. 받는 사람이 단정과 추정을 가려 옮길 수 있게 하는 칸이다

## HTML 규격

- **단일 파일.** CSS·SVG·폰트 전부 인라인. 외부 참조 0개 — 사내망·오프라인·메신저 첨부에서 그대로 열려야 한다
- 그림은 **인라인 SVG**로 그린다. mermaid는 렌더러 없이 안 그려지므로 이 산출물에서는 SVG를 쓴다
- JS 없이 정적으로 완성한다. 접기가 필요하면 `<details>`를 쓴다
- 색은 CSS 변수로 선언하고 `@media (prefers-color-scheme: dark)`에서 값만 바꾼다. `body`에 배경색을 명시한다
- 좁은 화면에서 1열로 떨어지게 한다 (`grid-template-columns: repeat(auto-fit, minmax(280px, 1fr))`)
- 인쇄·PDF 저장 대비 패널에 `break-inside: avoid`
- 본문 18px 이상, 패널 제목 28px 이상 — 회의실 화면 공유에서 읽히는 크기가 기준이다

## 검증 게이트

파일을 쓴 뒤 아래 검사를 돌린다. 실패하면 고쳐서 다시 돌린다.

```bash
grep -nEi 'https?://|<script|<link|@import|src="//' "$HTML" && echo "FAIL: 외부 참조 — 인라인으로 바꾼다" || echo "OK: 자족 파일"
```

`https://` 매치가 SVG 네임스페이스(`xmlns="http://www.w3.org/2000/svg"`)뿐이면 통과다 — 네트워크를 타지 않는 식별자다.

*완료 기준*: 외부 참조 0개, 패널 6~7개, 1번 패널만 읽어도 요지가 잡힌다.

## 보고

경로, 패널 수, 확인 못 한 항목 개수를 한 줄로 보고하고 여는 명령을 함께 준다.

```bash
open "$HTML"    # macOS
```

Artifact 발행(공유 링크)은 사용자가 **명시적으로 요청할 때만** 한다 — 기본 산출은 로컬 파일 하나이고, 그래야 Codex에서도 같은 결과가 나온다.

## 확정된 결론을 재피치할 때

`eli5` §확정된 결론을 재피치할 때의 계약을 그대로 따른다 — 확정된 결론만 옮기고, 판정을 새로 만들지 않는다.
차이는 하나: **공유물이 필요하다고 사용자가 말했을 때만** 이쪽이다. 그 말이 없으면 `eli5`(터미널)를 쓴다.
