# 운영 DB 조회 개통·작업 승인 준비

이 양식은 검토 자료다. 실행 권한은 [운영 DB 접근 정책](../policies/production-db-access-policy.md)의 인증된 승인 경로에서 발급한다. 의도: 목적·권한·한도·반출 범위를 같은 승인에 고정한다.

쿼리 형태는 제한하지 않지만 실행할 SQL 전문을 승인자에게 제시해야 한다. 전문·대상·owner·timeout·행·바이트 한도가 승인 payload와 달라지거나 명시 승인이 없으면 조회를 시작하지 않는다.

## 업무와 대상

- 요청자 / 티켓·장애 ID / 목적:
- DB 담당자 / 서비스 owner / 데이터 owner:
- 개발·로그·분석 DB로 확인하기 어려운 이유:
- 엔진·버전 / 대상 ID / DB / 복제본·primary 역할:
- 조회 객체·반환 열 / 템플릿은 선택 사항:
- 실행할 SQL 전문 (요약·파일 경로로 대체하지 않음):
- 승인 payload digest (승인 서비스가 SQL 전문·owner·target·timeout·행·바이트 한도로 재계산):
- 허용 파라미터 범위 (민감 실제 값은 보호된 경로로 전달):
- 결과 종류 / 데이터 기준 시각·복제 지연 허용치:
- 세션 격리 수준 / 실제 RCSI·SNAPSHOT 설정 / 읽기 충돌 검증:
- NOLOCK 허용 여부 / 근삿값 진단 목적·오차 허용 근거 (기본 미허용):

## 한도와 반환

- 승인 만료 시각 (기본 30분) / 이 승인 사용 횟수(1회):
- 실행 timeout (0초 초과 60초 이하) / DB 잠금 대기 제한(적용 시) / 서버 취소 검증 증거:
- 이 실행의 최대 행·바이트 (2026-10-15 사용자 지시로 기본 모두 제한 없음; 실행 시간만 제한):
- 전체 운영 DB·에이전트 전역 동시 슬롯 확인:
- 서비스 지연·잠금·복제 지연 중단 임계치:
- 반환 열·마스킹·최소 집단 크기 / 저장·반출 범위:
- 감사 저장 위치·보관 기간·열람자 / 회수 담당자:

## 개통 증거와 승인

- DB 최소 권한 / 직접 연결 차단 / 인증서 검증 증거:
- SP 생성·변경·삭제 및 EXEC 거부 증거 (조회 승인으로 변경 허용 불가):
- SQL 전문·target·owner·timeout·행·바이트 변경, 위조·만료·회수·재사용·전역 슬롯 초과 거부 증거:
- 결과·오류·로그 민감정보 제거 / 감사 장애 차단 증거:
- 중단·회수 시 서버 쿼리 종료 / 실제 Claude·Codex 실행 검증:
- 사용자 직접 중단 UI/CLI 위치 / 별도 비상 경로 / 전체 중단 권한 소유자:
- worker 정지·DB 통신 실패·감사 장애·재시작 시 차단 유지 / 무단 재개 거부 검증:
- 중단 접수·서버 종료 실측 시간 / 종료 미확인 표시 / 복구 담당자:
- 승인자 / 승인 시각 / 적용 프로파일·정책 버전:
- 인증된 승인 서비스의 발급 ID (이 문서의 값만으로 실행 허용하지 않음):
